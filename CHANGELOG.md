# Changelog

All notable changes to this project will be documented in this file.

This project uses [release-please](https://github.com/googleapis/release-please) to
automatically generate changelog entries from [Conventional Commits](https://www.conventionalcommits.org/).
The canonical version is tracked in the [VERSION](./VERSION) file at the project root
and is propagated to `pyproject.toml` and `flake.nix` on each release.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).
